# Emulator core (atem-emu)

The switcher itself — the ATEM Mini's network protocol, state and behaviour —
as a library shared by the emulator app and `atem-emu.exe` (the same switcher
with a console instead of a window).

How it works, the rules the recordings showed, its limits and how to build
it: **[docs/core.md](../docs/core.md)**.
