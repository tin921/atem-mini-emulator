# SDK functions the ATEM Mini has and that are safe to call, but that need
# hardware this project doesn't have (no HyperDeck, no Blackmagic camera):
# without it the switcher only answers "nothing connected", so a recording
# would not show the real behaviour. See docs/sdk-functions.md, Hardware.
# Interface or Interface::Method<TAB>hardware needed
# When the hardware is connected, remove the line: the methods become sweep
# targets (category 3). categories.py counts these as "needs hardware".

IBMDSwitcherHyperDeck	a HyperDeck on the network, connected to the ATEM
IBMDSwitcherHyperDeckIterator	a HyperDeck on the network
IBMDSwitcherHyperDeckClip	a HyperDeck with clips
IBMDSwitcherHyperDeckClipIterator	a HyperDeck with clips
IBMDSwitcherCameraControl	a Blackmagic camera on an HDMI input (camera control over HDMI)
IBMDSwitcherCameraControlParameterIterator	a Blackmagic camera on an HDMI input
