# SDK calls atem-sweep never makes. Everything else is exercised: settings
# are changed and put back; stored content (macros, stills) is created,
# changed and deleted only by the storage tests (s.), inside a backup-
# protected run (backup first, restore and verify after; see README).
# What stays here can't be undone, needs hardware the setup lacks, or does
# not exist on the ATEM Mini. categories.py counts these as "destructive",
# except opt-in actions (a reason containing --allow-...).
# Interface::Method<TAB>reason
IBMDSwitcherSaveRecall::Save	overwrites the saved startup state (it can't be read, so it can't be put back)
IBMDSwitcherSaveRecall::Clear	clears the saved startup state (it can't be read, so it can't be put back)
IBMDSwitcher::SetVideoMode	reconfigures the switcher: every output goes black for a while, and it can clear the media pool
IBMDSwitcher::SetAutoVideoMode	auto video mode can change the video mode (see SetVideoMode)
IBMDSwitcherHyperDeck::Record	starts recording on a HyperDeck
IBMDSwitcherCameraControl::SetFlags	camera action (instant autofocus) on a Blackmagic camera; runs with --allow-camera
IBMDSwitcherClip::UploadFrame	clips (not on the ATEM Mini)
IBMDSwitcherClip::SetValid	clips (not on the ATEM Mini)
IBMDSwitcherClip::SetInvalid	clips (not on the ATEM Mini)
IBMDSwitcherRecordAV::StartRecording	starts recording (not on the ATEM Mini)
IBMDSwitcherRecordAV::StopRecording	stops a recording (not on the ATEM Mini)
IBMDSwitcherRecordAV::SwitchDisk	switches the recording disk (not on the ATEM Mini)
IBMDSwitcherStreamRTMP::StartStreaming	goes live on the internet (not on the ATEM Mini)
IBMDSwitcherStreamRTMP::StopStreaming	stops a live stream (not on the ATEM Mini)
